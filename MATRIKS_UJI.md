# Matriks Pengujian Aplikasi Finding Kost (Minimal 20 Uji & Bukti Perbaikan)

Dokumen ini memuat matriks pengujian 20 skenario wajib pada aplikasi **Finding Kost** untuk memastikan seluruh fitur frontend, validasi, penanganan state, navigasi, dan antarmuka berjalan konsisten sesuai kriteria UTS[cite: 16, 18].

---

| **7** | **Validasi** | Batas Panjang Teks | Memasukkan teks judul kos yang sangat panjang (>100 karakter). | Teks terpotong (*ellipsis*) dengan rapi di card tanpa merusak tata letak UI. | Teks judul meluap (*text overflow*) ke bawah card. | Menambahkan properti `overflow: TextOverflow.ellipsis` dan pembungkus `Expanded` pada judul. | **BERHASIL** |
| **8** | **Validasi** | Pilihan Kategori Unselected | Menambah kos baru tanpa memilih kategori di Dropdown. | Sistem secara otomatis menetapkan kategori default atau menampilkan error. | Error `null check operator used on a null value`. | Mengatur nilai default `_selectedCategoryId ??= 'cat_1'` pada inisialisasi state form. | **BERHASIL** |

| **10** | **Data & State** | Hasil Cari Kosong | Ketik kata kunci pencarian acak seperti "XYZ999" yang tidak ada di data. | Tampilan *Empty State* muncul dengan ikon dan pesan "Tidak ada kos yang cocok". | Layar menjadi putih kosong tanpa informasi bagi pengguna. | Menambahkan pengondisian `if (filteredKost.isEmpty)` untuk menampilkan *Empty State Widget*. | **BERHASIL** |

| **12** | **Navigasi** | Tombol Kembali (Back) | Tekan tombol panah kembali pada AppBar di `RegisterScreen` atau `DetailScreen`. | Aplikasi kembali ke layar sebelumnya secara mulus tanpa error stack. | Layar hitam atau aplikasi keluar secara tidak sengaja. | Memastikan penanganan navigasi menggunakan `Navigator.pop(context)` yang valid. | **BERHASIL** |
| **13** | **Navigasi** | ID Salah / Data Null | Mengakses `DetailScreen` saat ID item tidak ditemukan di daftar state. | Aplikasi menampilkan widget fallback "Data tidak ditemukan" dengan aman. | Aplikasi mengalami kueri error (*Uncaught Exception*). | Menambahkan penanganan `errorBuilder` pada gambar dan validasi ketersediaan objek sebelum ditayangkan. | **BERHASIL** |
| **14** | **Navigasi** | Akses Rute BottomBar | Berpindah-pindah tab menu (Beranda, Kategori, Profil) pada `MainNavigationScreen`. | Indikator tab aktif berpindah dan halaman berganti secara konsisten. | Halaman tidak berganti saat tab ditap. | Menghubungkan `currentIndex` pada `BottomNavigationBar` dengan `setState` pengubah index. | **BERHASIL** |
| **15** | **Async Simulasi** | Loading State Data | Membuka katalog kos saat proses pemuatan awal data simulasi. | Indikator loading (`CircularProgressIndicator`) tampil sejenak sebelum data muncul. | Layar sempat membeku (*freeze*) sebelum data dirender. | Mengintegrasikan simulasi jeda pemuatan `Future.delayed` dengan pengondisian `isLoading`. | **BERHASIL** |
